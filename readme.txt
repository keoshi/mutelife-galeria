Automatically generate beautiful galleries with Gutenberg blocks!

== Description ==

Flexible image galleries that present every image at the same row height regardless of aspect ratio, with optional layout templates for more deliberate compositions (e.g. one tall + three wide).

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/mutelife-galeria`, or install through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
